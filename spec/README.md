# Omniform 0.1 specification

The normative core is deliberately small. A `Company` declares purpose, outcomes, required capabilities, resources, policies, evidence, and observations. Keywords **MUST**, **SHOULD**, and **MAY** are normative. JSON Schema is the mechanically enforceable contract; these documents explain its meaning.

The portable concepts are [Company](company.md), [Outcome](outcomes.md), [Capability](capabilities.md), [Capability Realisation](realisations.md), [Operation](operations.md), [Resource](resources.md), [Schedule](schedules.md), [Policy](policies.md), [Evidence](evidence.md), [Observation](observations.md), [State](state.md), [Plan/apply](plans.md), and [drift](drift.md). Implementations MUST NOT invent a top-level portable primitive merely for interface convenience.
