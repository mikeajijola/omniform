# Omniform 0.1 specification

The normative core is deliberately small. A `Company` declares purpose, outcomes, required capabilities, resources, policies, evidence, and semantic monitors. Keywords **MUST**, **SHOULD**, and **MAY** are normative. JSON Schema is the mechanically enforceable contract; these documents explain its meaning.

The portable concepts are [Company](company.md), [Outcome](outcomes.md), [Capability](capabilities.md), [Resource](resources.md), [Policy](policies.md), [Evidence](evidence.md), [State](state.md), [Plan/apply](plans.md), [drift](drift.md), and [semantic monitors](semantic-monitors.md). Implementations MUST NOT invent a top-level portable primitive merely for interface convenience.
