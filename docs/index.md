# Omniform documentation

Omniform defines portable Company-as-Code meaning. Choose a path:

- **Founder or operator:** [build the minimal company](getting-started/minimal-company.md), then learn [capabilities and actors](concepts/capabilities-and-actors.md) and [observations](concepts/observations.md).
- **Enterprise or business architect:** read the [core specification](../spec/README.md) and contribute reusable knowledge under `library/`.
- **Developer, AI-agent builder, or integration author:** use the [schemas](../schemas/omniform.schema.json), [conformance guide](reference/conformance.md), fixtures, and generated [operation reference](reference/operations/generate-plan.md).
- **Contributor:** read [CONTRIBUTING](../CONTRIBUTING.md), governance, RFCs, and ADRs.
- **Founder or founding-system builder:** see [how a reviewed draft becomes Omniform](guides/founding-to-omniform.md).

The files in this repository are canonical. Published pages identify the source revision through the GitHub Pages deployment.

Define once in Omniform. Execute through OmniSeed. Experience through any interface.
