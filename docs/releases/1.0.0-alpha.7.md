# `@omniseed/omniform` 1.0.0-alpha.7

This alpha makes the bounded autonomous-stewardship declaration merged on `main` under issue #25 available to package consumers.

Before this release, the `alpha` package channel exposed the older declaration contract. From this release, consumers can declare `recommend`, `autonomous_safe`, or time-bounded `autonomous` stewardship with activation and expiry, an operator-controlled state reference, triggers, limits, mandatory gates, protected categories, separated duties, and after-merge reconciliation.

Downstream repositories must consume the immutable version `@omniseed/omniform@1.0.0-alpha.7`, not the moving `alpha` tag. The declaration remains Provider-neutral and contains no executor, credential, approval result, or runtime state.

## Verification and publication boundary

- `npm test` validates the schema, semantics, examples, bounds, expiry, protected categories, and separation of duties.
- `npm pack` must include the schema, validators, documentation, and this note.
- A clean consumer must install the packed artifact and validate `examples/stewardship.omniform.yaml` through the package API.
- The implementation head must receive independent review without changing before merge.
- Only after that merge may a coordinator dispatch `.github/workflows/publish.yml` on `main` with version `1.0.0-alpha.7`.
- The resulting workflow run, merged revision, and npm registry version are the attributable publication evidence. Until they exist, downstream publication and integration issues remain blocked.

Machine-readable release evidence is in [`1.0.0-alpha.7.json`](1.0.0-alpha.7.json).
