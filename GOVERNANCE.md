# Governance

Maintainers steward the portable core through public issues, RFCs, and pull requests. Substantive changes—new primitives, state or plan semantics, package semantics, compatibility guarantees, or semantic-monitor semantics—require an accepted RFC. Reusable library additions normally do not. Decisions should favour interoperability, actor neutrality, evidence, and the smallest stable core.

Maturity labels communicate review level without preventing experimentation. Maintainer and release roles will be documented as the contributor community forms.
